# INF512-Unidad1-POO
## Descripción del Proyecto
El presente repositorio tiene como objetivo demostrar los principios básicos de la programación 
Orientada objetos (POO) en el lenguaje C#.
Se desarrolla una clase llamada yate, que representa un objeto con atributos y comportamiento propio,
aplicando los conceptos de estado, comportamiento, abstracción y encapsulamiento.
